# Proposal

## Why

Control Line's screens now come from an authored UI asset, but they still look like a default theme: grey buttons, white sample text, no art, and they are not shown reliably on HiDPI windows. A design exists (artifact "Control Line Redesign": navy field, orange accent, condensed display type, outlined buttons, translucent HUD panels, a track illustration) and the game should look like it.

## What Changes

- Make the screens actually render in the game window on HiDPI displays and lay out as authored (the root column's centring is ignored today); cover both with a test that reads pixels.
- Add the visual language of the design to the `screens` UI asset: colour tokens, named styles (primary and outline buttons, panels, HUD panels, table rows, muted and accent text), a bundled font pair and pre-rendered illustrations. All ten screens use it, including those the design does not draw (assist select, pause, pattern HUD, score tabs, debrief), which follow the same tokens.
- Bundle two open-licensed font families as bitmap-font resources of the asset, generated by a repeatable tool from the source fonts, and generate the illustrations (menu track with plane, plane top view) as PNG resources.
- Add one style key to the UI renderer, `uppercase`, so a label can show upper case while its bound or authored text stays as the game publishes it.
- Not changed: screen flow, texts the game publishes, bindings and actions (`GameUiContract`), keys, the 3D field behind plane select, rounded corners and letter-spacing (not supported by the renderer; the design's look is kept without them).

## Capabilities

### New Capabilities
- `control-line-ui-style`: how the game's screens look: palette, type, button and panel styles, the illustrations, legibility over the 3D view and correct display at any window scale.

## Impact

- `projects/app-game-control-line/project/ControlLine/assets/screens/` (meta.json, fonts, images), a new generator under `projects/app-game-control-line/tools/`, `GameUiHost` (sizing), `projects/lib-core` (`uppercase` style key, layout centring fix, tests), `characterization/screens.golden` (re-recorded once, reviewed), Control Line README and `docs/ai/file-formats.md` (style keys).
